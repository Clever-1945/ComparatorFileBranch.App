## ComparatorFileBranch.App


![Image](./screenshots/2026-01-10_13-56-29.png)

Приложение для сравнения локального файла и в этого же файла в ветке git
Приложение запускается с аргументами.

ComparatorFileBranch.App.exe "d:\projects\Wpf\Jarvis.App\Jarvis.App\MainWindow.xaml.cs"

Это полный путь до файла для сравнения.
